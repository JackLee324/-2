## 如何再次修改密码

**推荐方式（同时更新密码与 Token）**：登录后台 →「⚙️ 安全设置」。

**手动方式**：直接编辑 `server/data/admin_auth.json`：

```json
{
  "adminPassword": "你的新密码",
  "adminToken": "你的新Token"
}
```

改完重启服务生效。注意该文件**不要**提交到 git。

---

## 找回密码

直接查看 `server/data/admin_auth.json`。

若该文件被删除，重启服务时会自动生成一组随机强凭据，
并把新密码打印在启动日志中（`logs/server.out`），不会静默降级为弱口令。
